# 游戏界面、坐标投放与八个称号

## 交互

游戏Canvas采用与初始界面一致的墨绿、暖金色调和自定义描边／渐变面板，按钮包含悬停、按下、选中和禁用状态；坐标输入框使用同一风格。结束按钮位于重开按钮之前。时段图片已从Canvas移除，只显示日期、时段和季节文字。

Tab五行页中选择元素或地形工具后，填写地图坐标X、Y，点击“投放到坐标”。支持负数，坐标投放覆盖全图、不要求人物靠近，但仍检查地图范围、障碍、村庄建筑和矿点等原有规则。失败投放不算干预，不推进时间。选择工具不关闭页面；“返回”关闭。

教程在亲手播下的树苗达到木量3、长成树时完成，随后整个教学目标面板隐藏，直至重开。教程不再要求开矿、繁殖或繁荣；繁荣继续作为独立游戏目标。

V1World只有两个本局累计行为bool：`HasPlaced`、`HasMoved`。成功投放元素、调整地形或手动安排全图降雨将HasPlaced设为true；实际行走将HasMoved设为true。停止操作不会清零，只有ResetWorld重开才重置。系统传送、自然事件、树木散播和动物移动不计玩家行为。结算直接读取这两个标记。

## 结算与称号

结束游戏冻结本局操作，显示累计渡过的完整天数、剩余时段数和总时段数，一天按3个时段计算。称号可以同时获得多个，悬停或键盘选中显示条件。提供返回初始界面、再开一局、退出游戏。

| 称号 | 条件 |
| --- | --- |
| 运筹帷幄 | 本局未移动，结束时持续繁荣 |
| 自然守护者 | 结束时持续繁荣，全图无污染与死地 |
| 无为而治 | 本局没有投放、地形调整或手动降雨，结束时持续繁荣 |
| 山野自荣 | 结束时无存活村庄，生态持续繁荣 |
| 植树成荫 | 本局玩家播种成功建立至少12棵树苗 |
| 生灵繁盛 | 结束时至少12只存活野生动物，至少3种 |
| 四方烟火 | 结束时至少3座存活村庄，总人口至少48 |
| 岁月长流 | 本局累计300个时段，即100天 |

“结束时持续繁荣”指当前繁荣达到目标并保持指定时段，不能用历史曾经繁荣替代。无村庄时繁荣改按绿化、成熟树覆盖和野生动物计算，可独立达成。污染以每格0.001以内视为浮点清零，不以画面是否显示污染精灵代替检查。

结束时只保存实际符合条件的称号，PlayerPrefs键为`Riverbank.Honor.V2.<id>`，初始界面只列出历史已获得的称号，空列表不会列锁定称号。旧教学通关称号不自动换算成新称号。重开不产生奖励；结算预览也不写入称号记录。

## 实现与验证

- `V1World.cs`：累计bool、坐标入口、结束冻结与结算。
- `V1HUD.cs`、`V1HonorHover.cs`：游戏内界面和自定义悬停条件。
- `V1Honors.cs`：8项独立条件，可一次返回多项。
- `V1CanvasBuilder.cs`：自定义Canvas和UI素材，已有地图数据保留，仅升级UI。
- `RiverbankStartMenu.cs`、`RiverbankMenuSession.cs`：历史称号列表与存储。
