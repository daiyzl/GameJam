# 河岸繁荣 · 村庄生态世界

项目：`C:\Users\DLQian\GameJam`。新主场景：`Assets/Scenes/FiveElementsSettlement.unity`。Unity 菜单：**五行世界 → 村庄经营 → 打开河岸繁荣**。进入 Play 后，帮助河边的村庄扩建，维持食物、饮水和安全，使地图繁荣度达到 65，并连续稳定 5 个模拟步。成功后仍可继续游玩。旧教学场景保留。

## 操作

| 操作 | 按键 |
| --- | --- |
| 移动 | WASD / 方向键 |
| 打开 / 关闭独立资源页面 | Tab；页面内也可按 Esc |
| 选择五行 | 页面中点击，或数字 1–5（金木水火土） |
| 投放 | 靠近后按 E，投在朝向的格子；或点击距离人物 3 格内的地块 |
| 局部降雨 | Q，消耗库存 12 水 |
| 暂停环境 | 空格 / 暂停按钮 |
| 重开 | R / 重开按钮 |
| 查看村庄人口与环境 | 鼠标移到村庄；显示 6×6 影响范围和人口详情 |

资源页面会暂停环境和人物移动。选择一张卡片后回到世界；页面显示实际库存，无库存时按钮不可用。金、木、水、土缓慢补充，火和可投放动物有限。投放失败不会扣库存，村庄建筑格禁止投放。

## 村庄

初始村庄锚点 `(6,8)`，靠近河流。每个村庄读取锚点向左、下各 2 格，向右、上各 3 格的 **6×6 共 36 格**，不是半径 6 格。范围内统计水、植被、火、养分、金、动物和可居住地块。

- 饮水、食物、住房充足且没有火灾，人口增加。
- 周围投放金与木，村民自动消耗建材增加住房；初始住房 12，每次扩建增加 2，上限 48。
- 木、野生动物和养殖动物提供食物容量；养殖动物贡献更高。大量积水、河流与火灾降低可居住面积。
- 10 / 18 / 28 人是规模切换阈值，村庄图片随规模变化；人数直接显示在鼠标提示中。
- 缺水、食物不足或火灾会减少人口。环境持续恶化 10 步后，村庄迁往更宜居的区域；没有目的地时，村民搬离地图。
- 初始村庄必须靠近实际河流。后续村庄需要水源、食物与建材；已有村庄人口达到 20 时可分出居民建立新村庄。
- 一个村庄的 36 格内不会生成第二个村庄；检查双方范围，避免偶数边长方向带来的不对称。不同村庄的环境统计范围允许部分重叠。
- 新村庄和迁移目的地会避开人物当前所在的建筑占地格，防止建筑直接生成在玩家脚下。
- 全部村庄离开不会强制结束。改善有水、植被和建材的区域后，系统可再次吸引居民；也可重开。

这是第一版容量模型：村民食物、饮水以区域的承载能力表示，尚未逐个模拟村民劳动和每天食物库存。

## 重构后的五行

| 元素 | 当前作用 |
| --- | --- |
| 金 | 建造工具与建筑储备，村庄消耗金和木扩大住房；仅修剪木量超过 8 的过密树林，不再持续砍掉所有健康植被 |
| 木 | 食物、生境、燃料和建材；无火、有水与养分时生长，每增 1 木消耗 1 土、2 水；大树可向湿润邻格传播种子 |
| 水 | 村庄饮水、动物水源、植物灌溉和灭火；先灭火，再生长，沿地势流动；河流源格持续补水，过量积水会挤占居住地 |
| 火 | 烧掉木并留下灰烬，向干燥植被传播；超过金的耐火量才损伤金；火灾降低村庄健康、使动物逃离 |
| 土 | 生长养分、蓄水能力和地势的一部分；消耗于生长，落叶与动物粪肥少量回土；大量堆土会改变局部水路 |

同一格保留五种独立数量。环境每 0.8 秒更新一次，相邻影响用缓冲数组分阶段计算，避免计算顺序决定结果。地图 40×28，起始坐标 `(-4,-2)`；Tilemap 按坐标读取初始数据，每格无需挂脚本。

## 养殖和野生动物

新增透明 PNG：鹿、兔、牛、鸡，位于 `Assets/World/Settlement/Art/`；可拖入场景的 Prefab 位于 `Assets/World/Settlement/Prefabs/`。四种动物均支持 **养殖 / 野生** 两种来源。

- 鹿偏好树林，兔偏好草地灌木，牛需要较多草料，鸡偏好土地与种子。
- 野生动物选择附近食物、水源更好的格子，逃离火势；环境好时会有新动物进入地图。
- 养殖动物属于一个村庄，移动限制在其 36 格内。健康、食物足够时每 18 步可繁殖，单村最多 12 只。
- 养殖消耗少量草料并回馈养分。持续饥饿或火灾会失去动物。
- 村庄迁移后，养殖动物尝试转移到新村庄区域；村庄消失后，失去照料的动物回到野外。
- 当前使用单张待机素材，移动采用位置平滑和轻微摆动，尚未制作完整方向行走帧。

美术由内置 `image_gen` 生成，参考已有树与人物，提示词保存在 `art-prompts.json`。导入使用 Point、透明背景、无压缩与无 mipmap。

四张原始 PNG 的交付副本在工作目录 `SettlementWorld/Art/`，对应 Unity 项目中的同名图片；不会仅保留在生成工具的缓存目录。

## 开始建设的建议

鼠标移到初始村庄确认范围，在范围内建筑以外的地块投放金；在有植被的空地饲养动物，必要时补木、土与水。保留河岸的饮水点。过河可走南侧小径。改善其他河岸区域，并留出金储备，条件满足后新村庄会自行形成。

## 编辑和验证

退出 Play 后再编辑。场景根物体 `SettlementWorld` 的 `Settings` 可改步长、繁荣度目标、稳定步数和迁移等待步数；`Cell Seeds` 覆盖特殊格子的初始数量。Grid 下分别编辑地面、河流源格、桥、植被与障碍 Tilemap。河流源格用于逻辑，不显示渲染；运行水层会自动更新岸线。

Canvas 内的资源页、人口提示、目标和按钮都可在 Inspector 调整。规则代码是 `Assets/Scripts/Settlement/SettlementSimulation.cs`，显示与输入在 `SettlementWorld.cs`，不会改动旧的解谜模拟。

`Checks/Verify.ps1` 检查人口增长、缩小、迁移、搬离、新村庄排除、养殖繁殖、野生迁移、资源库存、繁荣通关与确定性。`Verification/Final/report.json` 记录实际 Unity Play 中的场景、碰撞、桥梁、资源页面、投放、动物和通关结果。

自动验证器仅消费显式的项目根目录 `SettlementVerification/request.json`，平时不会自行启动 Play。安装器保留用户修改过的文件；场景生成器打开已有新场景时不覆盖场景内容。

最终 Unity 验证：总人口从 8 增长至 44，新村庄 1 个，繁荣度 74.6，养殖繁殖 6 次、野生移动 31 次，运行错误 0。验证结束后世界恢复起点并暂停，按空格开始。实际键盘 Tab 开页、点击资源卡片与鼠标村庄人口提示也已检查。
