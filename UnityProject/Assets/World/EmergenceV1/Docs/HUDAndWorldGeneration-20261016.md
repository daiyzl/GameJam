# 视野、状态面板与完整随机开局

本轮更新已安装到实际Unity项目。普通开局由 `V1WorldGenerator` 生成，旧教学地图仅保留为回归测试底图。

- 只有外圈岩石边界固定。内部高低地形、弯曲主河、支流、湖泊、桥梁、道路、树木、矿点、死地、污染、动物、村庄和玩家出生位置按种子生成。
- 河道有连续的下降河床，河源通向出口，出口数量和能力覆盖上游输入。桥梁连接河流两侧的陆地，横向和纵向桥面与实际通行格一致。
- 村庄选择安全河岸，玩家出生在附近的安全地面；教学播种格随本局移动，不再固定为(7,6)。保留每格2粒种子上限和原有生态规则。
- 重开重新抽取地图种子。关闭Settings里的 `randomizeWorld` 并设置 `terrainSeed`，可重现同一地图；季节和操作序列相同时，生态结果可复现。
- 镜头正交尺寸从7缩小至4.5，附近物体约放大1.56倍。向前偏移从2.6缩小至1.6，人物不会因拉近而过于贴近下边缘。原有Point贴图采样和100%渲染比例保留。
- 顶部“目标与时间”整条背景和Title已移除。左上角保留工具、结束、重开三个按钮，右上角保留时钟和渡过时段按钮。
- 按 **M** 开关独立状态页，**Esc** 或关闭按钮也能关闭。面板显示繁荣、人口、村庄、时间、事件、生态分项、灾损、地图种子和最近反馈。打开时冻结玩家移动、阻止场景投放和推进时间；与Tab工具页互斥。
- 三个操作按钮背景不透明度22%，渡过按钮28%，时钟18%，地块数据24%；文字保持不透明并增加深色阴影，以便透过背景看场景。
- 教学完成后，“操作说明”和“教学目标”一起隐藏；地块数据下移到底边。重开会恢复教程说明。

四张生成地图各运行750天，均保留可用陆地，水账本误差绝对值小于0.12。规则报告：`Verification/HUD20261016/generated-worlds-report.txt`。
