## 繁荣

默认达到 **75分并连续保持9个时段（3天）** 才算持续繁荣。不要求玩家投放或移动；无为而治仍可自然达成，结算称号时仍读取本局锁存的 `HasPlaced` / `HasMoved`。

```
繁荣 = clamp((草木覆盖 + 成熟林地 + 水土余量 + 野生生灵 + 持续供养)
             × 林地平衡系数 − 污染/死地/积水/火灾扣分, 0, 100)
```

- 草木覆盖：20分，健康绿色陆地达到陆地75%时满分。
- 成熟林地：30分，健康成熟树格达到陆地18%时满分，树苗不计。
- 水土余量：20分。每块安全陆地的土以6、水分以0.8归一化，各10分；积雪按一半计入水分储备。
- 野生生灵：15分，按地图规模要求8～24只吃饱的野生动物，并要求至少3种；不把初始几只动物直接算满分。
- 持续供养：15分。有村庄时看各村的饮水健康、食物承载、住房、三时段木材储备与工具状态；无村庄时由水土及生灵共同支撑。
- 林地平衡系数：`0.35 + 0.65 × clamp(成熟林地比例 / 12%, 0, 1)`。人口和草地不能完全替代树林。
- 灾损：全图平均污染最高扣15分，死地、陆地积水、燃烧面积分别最高扣10分。水域污染也计入。

初始显示会计算真实分数，但不增加时段或稳定次数。每次正式时段结算，分数不足会清零稳定计数；历史 `Won` 不会代替结束时的当前繁荣判断。

## 随机地图与“无为而治”

每次新开局/重开会生成新种子，改变Perlin地形、远离教学村庄的土壤/水分和少量稀疏树苗，以及后续自然事件。初始村庄、道路、桥梁、河道与专门设计的资源点仍保留。不会随机赠送繁荣分，也没有强制干预才能获胜的判断。

地块数据栏显示实际地图种子。需要复现时，在V1World的Settings关闭 `randomizeWorld`，填写 `terrainSeed`，并选择同一季节；这会复现该种子的地形、初始生态和事件序列，同样的操作会产生同样的生态结果。纯规则验证入口是 `V1Level.Create(settings, seed, true)`。

24张地图各推进300时段（100天）的抽样中，4张曾自然繁荣，首次发生在80、186、214、263时段；没有一张在前12时段内完成。**这是样本观察，不是写死的成功概率，也不保证之后一直维持繁荣。** 一张普通地图未达成，一张幸运地图在第80时段自然获得“无为而治”资格的回归已覆盖。

## 污染助燃

污染可以作为可耗尽的燃料：每单位实际烧掉的污染释放0.22热量，扣除0.08处理成本，净增0.14火势；这种助燃最高将火推到12。人为投放的更强火仍保留原强度。

相邻干燥污染格也能积累预热并着火；新火需要延迟与预热，输出的传播热量会从火源扣除。污染燃烧可能引燃旁边树林和村庄。污染耗尽后不再提供热量，无燃料时火会衰减；河流和积水仍有强灭火作用。污染守恒账本继续记录实际消除量。

回归案例：6×6裸地每格污染80，中心仅投放1点火，峰值约9.81、发生59次蔓延，旁边6木量的树被烧毁。干净6木量树林里1点火仍只影响1格；河流水带能隔断污染火，燃料清空后火熄灭。
