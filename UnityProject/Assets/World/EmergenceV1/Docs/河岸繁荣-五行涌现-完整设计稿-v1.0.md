# 河岸繁荣：五行涌现完整设计稿 v1.0

日期：2026-10-09  
类型：俯视角 2D 像素生态建设沙盒  
背景：玩家调节五行与地形，帮助河岸村庄生存、增长和扩张。

## 1. 文档地位与设计目标

本稿整理本轮讨论的最终方向，作为下一阶段实现依据。替代旧版机关解谜设计中的有限库存、先布置后运行、水槽通关和倒计时失败设定。旧文档保留作历史参考。

本文中的“已确定”来自讨论中的明确选择；未逐项讨论的边界处理以“首版定稿建议”给出，方便形成可实现的完整规则。参数表是调试起点，不是已经验证过的平衡结果。

旧 Unity 村庄原型尚未实现本稿全部规则，旧原型的运行验证不能作为新规则的验证结果。2026-10-10新建了独立V1关卡，完成无限投放、草树区分、金富集与矿点、污染、泥沙、动态地形、真实库存及基本治理；实际实现口径与验收以补充稿和对应验证报告为准。

核心体验：投放元素或改变一处环境后，观察植物、动物、水流、矿物和村庄相互作用，找到让整体世界持续繁荣的方法。

## 2. 与“涌现”主题的关系

主题贴合的依据是：统一的局部规则产生未被逐步编排的整体结果。单个数量阈值、预制体生成、随机下雨，本身不足以体现涌现。

本设计的主要反馈链：

1. **金的迁移改变土地用途**：分散金压制树木 → 木归零形成死地 → 金向低处富集 → 原地金减少、停止产生死地污染 → 低处成矿 → 村庄可以开采。
2. **发展改变发展的条件**：矿山提供工具材料 → 村庄扩建与养殖增加 → 木材和草料需求增加、生产污染增加 → 环境承载力下降 → 村庄缩小或迁移。
3. **植被与水路互相改变**：树木减少 → 土壤侵蚀增加 → 泥沙被河流搬运 → 低流速处淤积、河床抬高 → 河水溢出 → 新湿地出现，原有居住地受淹。
4. **治理有后续代价**：火清理部分污染并产生灰烬 → 草木受损、地表失去保护 → 侵蚀风险增加；重新播种和保留植被可逐步恢复。

这些链条不由“经过多少秒自动触发繁荣／洪水／迁移”的关卡脚本执行。计时只用于生长、繁殖、持续风险等过程；是否发生由实际世界状态决定。

首版至少应让玩家清楚观察到其中两条完整链，并在同一张地图上找到两种不同的繁荣方案。否则规则虽多，主题表达仍可能只停留在普通数值经营。

## 3. 玩家操作与游戏循环

### 3.1 已确定的操作方向

- 玩家控制可移动人物，在连续世界中探索；底层使用网格记录环境。
- 金、木、水、火、土无限投放，偏自由沙盒；没有元素库存耗尽的失败。
- Tab 打开独立五行工具页，显示工具、投放量、作用和风险。
- 玩家可暂停、单步观察、恢复运行、主动重开。
- 鼠标指向村庄时显示人口与区域状况；指向地块时查看环境数据。
- 无限投放不等于直接设置人口、矿点或森林；这些结果仍由世界规则产生。

### 3.2 首版定稿建议

保留 WASD／方向键移动、数字 1—5 选元素、E 向面前投放、近距离鼠标投放、空格暂停、R 重开。投放半径建议 3 格，可改投放量；页面打开时暂停模拟。

木工具提供种子或幼苗，不直接增加村庄木材库存，也不瞬间生成树林。土工具补充养分；另设明确的“垫高／挖低”地形操作，避免玩家投一份土时同时改变养分和高度而无法判断结果。局部降雨属于水工具的可选模式。

游戏循环：观察缺什么或哪里失衡 → 局部干预 → 世界自行演化 → 根据反馈继续调整。玩家可以持续干预，但稳定环境也应能在一段时间内自行维持。

## 4. 世界与数据

### 4.1 每格数据

| 数据 | 含义 |
| --- | --- |
| 金 G | 尚未开采的矿物量；能压制木，也能迁移富集 |
| 木 W | 存活的木本植物生物量；不是草，也不是村庄库存木材 |
| 水 Q | 本格可流动水量 |
| 火 F | 火势；属于反应强度，不按水的方式守恒 |
| 土 S | 可用于生长的土壤养分 |
| 地形高度 H | 决定水面与金富集低点；独立于土壤养分 |
| 可侵蚀土体 | 可以被冲刷搬走的地表材料；与生长养分分开 |
| 泥沙 | 水中携带的沉积物及其养分／矿物成分 |
| 草覆盖量 | 草地生物量，提供草料与地表保护 |
| 种子、植物年龄 | 决定幼苗建立与树木成熟 |
| 污染 P | 独立环境状态，不是第六种元素 |
| 矿点状态 | 未成矿／固定矿点／枯竭遗址，不能仅由当前金量反推 |
| 地块标记 | 水源、出口、建筑、障碍、桥等 |

村庄另存人口、住房、食物状态、木材库存、金材库存、工具状况、养殖归属和持续缺口。动物另存种类、野生／养殖、归属、位置、健康及繁殖状态。

### 4.2 范围

- 水流、火传播、死地影响：本格及上下左右相邻格，不跨不可通行屏障。
- 金富集：以本格为中心的 5×5，包含本格，共 25 格。
- 村庄：固定 6×6，共 36 格；建议锚点坐标偏移为 x、y 各 −2 到 +3。
- 野生动物：读取附近可达的生境，逐格移动；不能用全图瞬移代替迁移。

环境邻接、金迁移可达性、人物通行分别判断。河水能够经过的边，不必允许人物直接走过；桥允许人物过河，不应自动截断水流。

## 5. 五行作用总表

| 元素 | 主要作用 | 风险与间接影响 |
| --- | --- | --- |
| 金 | 压制木本植被、向低处富集、形成矿山／矿洞；开采后供工具与建造 | 分散高金可能形成死地；采矿加工产生污染；矿物会枯竭 |
| 木 | 经种子形成幼苗、树和树林；提供栖息地、土壤保护、木材与燃料 | 被金压制、火烧和采伐消耗；消耗水、土；过量采伐削弱生态 |
| 水 | 饮水、灌溉、灭火、流动，搬运泥沙和污染 | 积水影响居住，污染可沿河扩散；河道淤积可导致洪水 |
| 火 | 燃烧、灰烬回土、受控生产、清理可燃污染 | 伤害植物、动物和建筑；消耗水；强火损伤金；失控可蔓延 |
| 土 | 生长养分、地表保水与植物恢复的基础 | 可耗尽或被冲走；泥沙过量沉积抬高河床，影响水路 |

不要求每对元素都有直接作用。间接影响是主题的重要部分，不需要补齐一张机械的五行克制表。

## 6. 草、种子、树与树林

### 6.1 已确定的植物规则

- 只有土和水、没有树木种子时，地块只能产生草。
- 有种子且环境合适才能出现树苗；树苗长成树，树林从树演化。
- 村庄木材只能从树或树林采伐获得，草不能提供木材。
- 木本植物增长按 `增加 1 木，消耗 1 土、2 水` 计算；缺土或缺水时停止。
- 地块有火时停止生长。火刚在本步熄灭，下一步才恢复生长。

### 6.2 首版定稿建议

- 草萌发需要水、养分、无有效火势且污染未超过抑制阈值；增长同样消耗资源，速度比树木恢复快。
- 草是独立变量。金对木的直接抑制不扣草；死地污染、干旱和火可以损伤草。因此 `W=0` 的死地形成时，可能短暂仍有草，随后按环境规则变化。
- 种子成功建立幼苗时扣除种子；不能因条件持续满足而每步重复生成同一棵树。
- 幼苗存活并积累生物量与年龄后成为树；成熟树产生少量种子，在邻近适宜空地建立新树。
- 树林是成熟树生物量与附近树木密度达到要求后的表现及生态状态，不允许投放大量水土直接跳过幼苗阶段。
- 火烧、污染、洪水或金压制可能使树林退化为树、幼苗或空地。
- 村庄采伐扣除真实 W，增加村庄木材；金抑制和火烧造成的 W 损失不增加木材库存。
- 采伐优先成熟树，保留一定活树；保留不足会降低后续木材供给和地表保护。
- 落叶、植物残体、动物排泄和灰烬可回补养分。回补来自实际生物量或已消耗食物，避免同一份材料被重复返还。

## 7. 金、死地与矿点

### 7.1 已确定的状态规则

设 `0 < a < b`。成矿边界在本稿统一为 `G ≥ b`，使恰好等于 b 时有明确状态。

| 状态 | 判定 | 金富集迁出 | 作用 |
| --- | --- | --- | --- |
| 普通含金地 | 未成矿，G < a | 可以 | 仍按 G 与 W 的比较影响木 |
| 高金植被地 | 未成矿，a ≤ G < b，W > 0 | 可以 | 金大于木时，木持续下降 |
| 死地 | 未成矿，a ≤ G < b，W = 0 | 可以 | 持续缓慢产生污染，影响邻地 |
| 固定矿点 | 曾达到 G ≥ b，尚未枯竭 | 不可以 | 可开采，可接收新金 |
| 枯竭矿遗址 | 固定矿点的剩余金已耗尽 | 没有金可迁出 | 无产出，保留遗址表现 |

矿点形成后即锁定位置。开采使金低于 b，甚至低于 a，也仍然是矿点，直到金归零；不会在开采过程中退回死地或重新向外迁移。

### 7.2 金对木

当同一格 `G > W` 且 `W > 0` 时，持续减少 W；`G ≤ W` 时，这条压制停止。新规则替代旧原型的“邻格工具切割＋连续切割倍率”。

首版可用 `木损失 = min(W, 抑制系数 × (G − W) × Δt)`。这属于抽象五行压制，不作为村民采伐。矿点也保留此作用，因此矿区难以维持树木。

### 7.3 金的富集

- 未成矿格的金在其周围 25 格中寻找地势最低的可达目标。
- 若自身已经是最低点，则保留金；最低点并列时优先自身，其次距离最近，再使用固定坐标顺序，避免无原因来回迁移。
- 每步只转移一部分金；总量守恒，不复制金。
- 固定矿点不向外富集，但可接收来自其他格的金。
- 富集统一提交后检查新成矿；本步刚收到的金下一步才再次迁移。
- 不额外增加水量前提：这是已选定的抽象矿物富集规则，可以在无水环境中缓慢发生。

首版定稿建议：在 5×5 范围内，用预先计算的可达关系选择低点，沿一条确定的通路每步最多移动一格。局部反坡允许通过，但跨墙或跨出搜索范围的路径不允许。矿形成后锚定优先，不再执行沿路径迁出。这样低点富集可见，又不会直接穿过障碍瞬移。

### 7.4 死地扩散与恢复

死地每步生成少量本格污染，污染向四邻格缓慢扩散并损害养分与植物。它影响周围地块的生态，**不直接给邻格增加金，也不把所有受污染地都判为死地**。

当原地金低于 a，或恢复了活木，停止死地源污染；已有污染继续存在。成为矿点后转用矿点规则，停止死地源污染，但开采加工仍可能污染环境。

恢复需要污染下降、养分和水适宜；树木恢复还需要种子。仅让金离开不会立即生成森林。

### 7.5 开采、材料与自然来源

- 村庄开采范围内可达、未枯竭矿点；需要基本饮水、食物、劳动力和安全条件。
- 开采扣除矿点 G，增加村庄金材库存。存在矿点但无法开采，不算有效供给。
- 多个村庄开采同一矿点，统一分配开采额度，不重复获得同一份金。
- 金材用于工具生产维护与建筑，充足时提高生产效率和扩张速度。
- 没有有效矿源时先消耗库存，再发生工具磨损、效率下降和衰退；不因矿点瞬间消失立刻扣光人口。
- 全图无矿、金源不能形成新矿且玩家不干预时，库存耗尽后村庄最终崩溃或搬离。

首版定稿建议：地图初始分布有限矿物；含矿土体被侵蚀时释放并搬运其已有金，沉积后进入地块金量。地块金富集与含矿泥沙搬运共用金账本，不能对同一份金重复转移。没有“每隔一段时间凭空生金”的机制。

矿山／矿洞首版共用经济规则，由地形或美术标记区分。枯竭后若再次被玩家补金或自然搬运金到达，清除旧矿点锁定并按普通含金地重新判断；重新达到 b 才恢复可开采矿点。

## 8. 水、土、泥沙与洪水

### 8.1 水流

水面高度为 `L = H + 水量换算系数 × Q`。水从较高水面流向较低水面的四邻格，因此同地形高度时，水多的格会向水少的格扩散。

- 每格总流出不得超过可用 Q；向多个方向流动时统一分配。
- 植被与土壤保水降低流速，不能凭空删除水。树林降低通量，不采用旧谜题中的“一片森林绝对封死河道”。
- 只有明确的上游源格补水；河道传水、地图出口排水。不是每一格河流都自行无限补水。
- 下雨给覆盖区域增加水。水源和雨量记为外部输入；植物消耗、灭火、蒸发和出口排水记为去向。
- 首版饮水按水源的可用性和洁净度提供承载能力，不逐人模拟取水路径；植物与灭火使用真实水量。

### 8.2 土壤与侵蚀

土壤养分 S、地形高度 H、可侵蚀土体是不同数据。植物消耗养分不直接挖低地面。真正冲刷地表土体才改变高度，并带走其中的养分与矿物。

- 流速／水面坡差越高，侵蚀能力越强。
- 草和树木覆盖减轻侵蚀；裸地、过度采伐地更容易被冲刷。
- 快水搬运泥沙，慢水沉积泥沙；沉积量受携带量约束。
- 少量沉积能补充下游养分；大量沉积提高地形、抬高河床，减少河道通水能力。
- 养分消耗、回补、搬运单独记账；高污染削弱养分和保水能力的过程需有明确损耗记录。

### 8.3 洪水与荒漠化

洪水不是只由降雨触发，也不由“泥沙到达阈值就播放事件”触发。

持续上游来水＋局部河床淤高／出口通量不足 → 水面升高 → 水自然流入旁边较低土地 → 积水持续超过建筑、植物或动物耐受限度，产生洪水伤害。

淤堵常使堵点上游及周边先漫水，具体方向由地形决定。下游积水不是固定写死的结果。

上游岸坡失去土体与养分后，保水能力下降；低降雨时段更容易干燥，植被逐步减少，可能成为荒地。仍被河水覆盖的格子不会同时显示成干燥荒漠。

## 9. 火、生产与污染治理

### 9.1 基础火规则

- 玩家投放、受控炉火外泄或邻格火势传播可以点燃地块。首版不使用无缘由随机自燃；雷击属于后续天气扩展。
- 火再少，只要未被水扑灭且有可燃物，就能缓慢烧草或木。
- 水先压制火。剩余火势和可燃物共同决定燃烧速度；实际燃料消耗决定火增长与灰烬回土。
- 无燃料时火衰减；土、金、洁净水本身不作为普通燃料。
- 烧掉的植物部分转为养分，部分损失；回土比例不大于实际被烧掉的材料。
- 新火下一步才燃烧或传播，避免单步贯穿全地图。
- 建筑受持续火灾会损坏，动物逃离；建筑储存的木材可提供燃料，但不得同时被燃烧和用于建造。

### 9.2 火对金

保留“火不足时完全不能损伤金”的规则。首版建议本格灭火后的 `F > 金耐火系数 × G` 时才损伤金；未达到阈值不积累隐性伤害。

这是一条抽象五行规则。损伤的金记为不可回收材料损耗，不悄悄转成可开采金材。固定矿点也可能被强火耗尽。

### 9.3 污染来源与传播

首版污染代表游戏中的混合生态负担，并不模拟所有现实污染物。

来源：村庄生产与矿物加工、失控燃烧烟尘、死地持续输出。村民日常生活产生较小基础量。

传播：少量向邻地扩散；流动水携带污染向下游；污染不是每格凭空独立增殖。干地与水体共用污染总量，水运只搬移其中可运输份额。

影响：植物生长减慢、动物生境恶化、饮水质量下降、村庄健康与生产效率下降。村庄提示同时显示 36 格平均污染、主要饮水点污染和危险热点，避免平均值掩盖上游污染水源。

草木在适宜污染范围内缓慢净化；严重污染不能靠一棵树瞬间消除。

### 9.4 火清理污染的边界

火清理的是可燃废弃物等可处理份额。首版可用单一 P 配合每步处理上限表达，不必立即加入多类污染数据。

- 必须实际消耗木材或可燃物才能处理污染，不能在无燃料情况下永久净化。
- 只处理炉区或燃烧所在格及明确小范围，不直接清空整个村庄 36 格污染。
- 污染处理量有上限；持续源头未解决时会再次积累。
- 受控炉火净处理量为正；失控野火烟尘更大且损伤生态，整体后果可能更差。
- 火不把金移除等同于免费净化，也不使矿区、死地和饮水源自动恢复健康。

### 9.5 村民自动清理还是玩家清理

首版定稿建议：两者都有明确职责。

村民在有炉具、燃料、可用水与安全条件时，自动处理日常积累的污染；超过启动阈值后进入治理，降到停止阈值后退出，避免开关抖动。治理期间消耗木材并占用生产能力。

玩家负责建立可工作的环境、治理远处死地与上游源头、处理大范围火灾和洪水。村庄污染超过阈值，不会直接在全区生成火焰。

炉具由村庄用已有金材、土与木材建设，炉火是受控生产状态。燃料过多、周边过干或安全水源不足且炉火超出容纳能力时，可能产生外泄火；只有超过风险条件并持续一段时间才外泄。

火灾传播要求邻接火源、可燃物和不足的湿度／隔离。水路、少燃料地块、隔离带可阻止传播。野火阈值用于显示危险和伤害，不替代真实传播。

## 10. 动物：野生与养殖

鹿、兔、牛、鸡均支持野生和养殖两类；种类与归属是不同概念。

| 种类 | 主要生境与食物 | 养殖特点 |
| --- | --- | --- |
| 鹿 | 林缘与树林附近的草、叶，附近有水 | 需要较大植被空间 |
| 兔 | 草地与低矮植被 | 草料充足时繁殖较快 |
| 牛 | 开阔草地与充足草料、水 | 食物需求高，稳定供给能力较强 |
| 鸡 | 草地、种子及适宜土地 | 占地较小，需要持续食物 |

### 10.1 野生动物

- 逐格寻找更好的草料、林缘、水源与安全条件，逃离火和严重污染。
- 移动允许小范围探索，但不以随机生成替代生境选择。
- 足够健康、食物与空间时繁殖；缺食物和恶劣环境会减少数量或离开地图。
- 地图边缘可以在生境适宜时出现迁入个体，有冷却与种群上限，防止每步条件满足就刷动物。
- 野生动物主要贡献生态与多样性。首版不把每只野生动物直接算成可永久提供的村庄食物。

### 10.2 养殖动物

- 有明确所属村庄；在其可达活动区域与牧场范围内移动，不因范围重叠同时归属两个村庄。
- 养殖消耗真实草料／饲料；饲料预留统一结算，不能让多个动物重复吃同一份草。
- 持续食物、水和健康条件满足后繁殖，受牧场容量限制。
- 为村庄提供稳定食物承载力；首版用简化产出效率表示，不必建立完整屠宰和物流系统。
- 排泄养分来自已经消耗的食物，不作为无限凭空造土。
- 村庄迁移时尝试随行；被遗弃的动物转为野生或因生存条件恶化消失。

首版定稿建议：初始村庄配置少量种畜，后续由自然繁殖与新村庄转移获得。无限五行投放不额外增加无限刷动物工具。

## 11. 村庄的建立、发展与衰退

### 11.1 选址与 36 格范围

- 初始村庄靠近河流，并有可使用的洁净水源。
- 每个村庄读取 6×6 范围；范围允许重叠。
- 新村庄中心不能进入已有村庄范围。首版对双方中心都检查，避免偶数边长的方向性造成不对称。
- 建筑不能重叠、堵死唯一通路或生成在玩家脚下。
- 后续建立还需要安全住地、食物、木材与金材；水源可以是适宜河流或稳定水体，不必全部紧贴同一条河。

范围重叠只允许共同读取生态条件，不允许复制库存。矿石、草料、采伐木材和共享住房占地按实际资源统一预算。两个村庄使用同一生态区会增加压力。

### 11.2 发展条件

人口增长需要持续满足饮水质量、食物承载、住房、安全与基本生产条件。

有效矿源提供金材，树木提供木材，村庄消耗库存修建房屋与工具。资源充足可以加速发展，但不能绕过食物和住房上限。

规模通过房屋数量、道路／牧场与占地变化体现；不能只放大同一张村庄图片。人口减少后可能闲置或废弃建筑，不要求每掉一人就立刻拆房。

首版保留聚合村庄状态，不逐个模拟村民路径；真实资源库存与环境承载条件都需要记录。

### 11.3 衰退与迁移

- 缺水、饮水污染、缺食物、持续矿材断供、火灾或洪水使健康和生产下降。
- 短暂缺口先使用库存／储备，持续缺口导致人口减少、房屋停用。
- 连续恶化超过等待期后寻找更适宜且合法的区域；迁移需要可达路径，不能隔山全图瞬移。
- 无合适目的地则居民逐步离开地图。
- 新村庄由人口与储备足够的旧村庄分出居民建立；扣除原村人口和建造储备，不凭空复制居民。
- 全部村庄消失后，玩家仍可恢复环境；合法河岸重新满足建立条件并持续足够时间，可从地图边缘吸引新居民。

## 12. 繁荣、通关与重开

### 12.1 通关

已确定：以地图繁荣度达到目标作为通关。首版建议 0—100 分，达到 65 且持续 5 个模拟步后成功；成功后允许继续沙盒。

建议构成：

| 项目 | 上限 | 计算边界 |
| --- | --- | --- |
| 健康居民规模 | 40 | 按健康加权人口，有上限；不只看人数 |
| 村庄生活质量 | 20 | 饮水、食物、住房、安全与生产可持续性 |
| 植被生态 | 20 | 草与成熟树共同计分，成熟林权重更高；按地图格子去重 |
| 野生动物生态 | 10 | 健康种群与种类，多样性有上限 |
| 养殖支持 | 10 | 按有实际饲料支持的有效养殖产能计分 |

没有健康在住村庄时，不能仅靠树和动物判为“村庄繁荣”通关。污染与灾害通过健康、有效生态和生活质量降低分数。直接堆金或无限刷数量不能无限加分。

### 12.2 失败与恢复

本作采用软失败：村庄缩小、迁移、搬离和生态破坏，不自动强制重开。无限干预使玩家仍有恢复机会。

全村离开时提示“村庄已搬离，改善水源与生境可以吸引新居民”，同时提供重开按钮。教学任务可以失败并重试，但主沙盒没有隐藏倒计时。

重开恢复地图、初始居民、动物、库存和天气种子；保留玩家界面设置。

## 13. 条件生成、Tilemap 与 Prefab

- Grid／Tilemap 负责地面和坐标；每个格子的数据位于统一状态数组，不要求每格 Inspector 都挂元素脚本。
- 初始环境可由 Tile 类型默认值、地块种子配置和特殊覆盖数据构建。读取 Tilemap 使用格坐标，不把 active target 当单一环境物体。
- 检测条件后先更新逻辑状态，再创建／切换对应的表现。
- 草和水面优先使用 Tilemap。树苗、树、树林、矿山／矿洞、动物、村庄建筑使用 Tile 或 Prefab，按交互需求选择。
- 同一个对象只生成一次；状态改变时替换、升级或销毁，不能每个 Tick 因条件仍满足而再次 Instantiate。
- 预制体是逻辑结果的表现，不负责各自重新扫描整张地图并重复计算环境。
- 混合元素地面通过基础地形＋草／树覆盖＋水层＋矿物／污染细节＋火效果组合，不为每种数量组合制作独立贴图。
- 下雨粒子是视觉效果，雨量由天气逻辑写入地块；粒子落点不作为资源来源。水体、火势、灰烬、污染应有不同可读表现。

## 14. 模拟顺序、预算与性能

建议固定逻辑步长 0.5 秒；渲染插值独立。下列阶段各自先读取快照、预留资源，再统一提交，允许下一阶段读取上一阶段结果。

1. 应用玩家命令、天气与水源输入；记录本步开始的火状态。
2. 水压制火；处理已有燃烧、强火损金、灰烬与局部污染处理；新火仅登记供下一步使用。
3. 金富集及含矿材料预算结算，判断新矿点与死地；本阶段输入不得再次迁出。
4. 在步开始无火且当前也无火的格子计算草、树与种子增长；金压制、污染伤害统一限制可用生物量。
5. 村庄采伐／采矿、动物取食和村庄建造统一预留共享材料；动物与村庄状态读取实际获得量。
6. 水流搬运污染和泥沙；侵蚀、沉积统一提交；新流入的水下一步才供植物或灭火使用。
7. 污染源与扩散、动物移动繁殖、人口变化与迁移结算；变化影响下一步资源条件。
8. 更新对象状态和表现，计算繁荣与通关。

每个阶段不允许边遍历边修改共享地图给后面的格子读取。燃烧、采伐、金压制争用木时不能各自扣掉整份木；按阶段和剩余量结算。民用金材与未开采 G 属于不同库存。

数量使用小数或定点单位，资源不足时按比例降低反应，不因取整让微弱火或缓慢流动永久停住。所有数值非负；超过容量的增长停止，不能暗中删除没有记录的资源。

性能：环境本地反应与四邻流动为 O(N)，金搜索固定 25 格为 O(25N)；村庄统计 O(36V)。40×28 地图一次直接金搜索约 28,000 次候选读取，这只是量级估算，不能当作实测帧率。

首版全图扫描，预分配缓冲数组，预计算障碍稳定时的金可达关系；高度变动只更新低点选择。避免每格多套 MonoBehaviour／Update，Tilemap 只更新发生变化的格子。性能是否需要分区由 Unity Profiler 实测决定。

## 15. 信息呈现

- 顶部：繁荣度、人口、运行／暂停、最近的重要环境变化。
- Tab 页：五行工具、投放量、作用、预计局部结果；不再显示有限库存。
- 地块提示：G、W、Q、F、S，草、种子、污染、高度、矿点状态及当前变化原因。
- 村庄悬停：人口、规模、36 格边界，水质、食物、住房、木材／金材、工具、动物与迁移风险。
- 对死地提示“木为零且 a ≤ 金 < b”；对矿点提示“已固定，开采到枯竭”；低于 b 仍显示矿点锁定。
- 水显示流向、积水和淤积风险；金显示慢速迁移方向；污染热点使用可辨认覆盖效果。
- 重要事件显示原因，例如“上游污染使饮水质量下降”“河床淤高导致旁侧漫水”“矿材储备耗尽，工具效率下降”。

玩家应能从界面理解反馈链，不需要阅读公式才能正常游玩。

## 17. 教学关卡与 Jam 范围

使用一张河岸地图渐进提示，不切成纯数值网格实验室。

1. **认识生长**：给湿润空地补土，看草出现；播种观察幼苗，明确草不提供木材。
2. **支持村庄**：保留树木、水源和草料，让初始村庄采伐、养殖并增长。
3. **认识富集**：观察一组含金高地向低点迁移，形成矿点；矿点支持村庄工具与建设。
4. **治理环境**：生产污染增加后，学习炉火与供水；保留植被并解决源头。
5. **观察连锁**：显示已有泥沙搬运与淤积，让玩家恢复流路或调整植被，最终维持繁荣。

教学只检查结果与提供提示，不代替系统制造矿点、洪水或人口增长。可以通过初始布局加快观察，但不能用脚本强制事件结局。

Jam 必须完成：无限五行工具、草／树／种子、金压制／富集／锁定矿点、基本水流、村庄真实木金库存、基础污染与火治理、野生／养殖区分、繁荣目标和原因提示。

泥沙与河床变化先使用简化规则完成一条可读链；复杂天气、雷击、完整村民物流、多类污染、精细地下矿层、建筑科技树放到后续。首版不继续增加元素或系统数量，先让已选规则产生可观察的反馈。

## 18. 实现后的验收

- 无种子湿地只能出草；草不能进入村庄木材库存；树林必须经过树的阶段。
- 树木增量、植物耗水耗土、采伐与库存转移能够对账，无重复消费。
- 同格 G>W 才触发金压制；死地仍要求 W=0；受污染邻格不会凭空生金。
- 金富集守恒且不穿障碍；等高不会反复振荡；每步传播距离受限。
- 金达到 b 形成矿点；开采跌破 b／a 仍固定，归零才枯竭；共享开采不复制矿材。
- 无矿供给时表现为库存耗尽后的逐步衰退，不是检查全图矿数后直接删除村庄。
- 同高地水多向水少流动；只有源头补水；污染与泥沙搬运能对账。
- 不下雨时，上游持续来水与河床淤积也能导致真实溢流；上游岸坡损失与下游沉积能观察到。
- 弱火能烧植物、不能损伤未达到耐火阈值的金；无燃料火会衰减；治理有材料成本和局部范围。
- 村庄范围可重叠，中心规则正确；共享资源只扣一次；养殖归属唯一。
- 野生动物能按生境迁移，养殖需要饲料和水，繁殖受容量限制。
- 同一初始状态与操作序列，在暂停、单步、正常速度下结果一致。
- 相同规则在至少两个不同布局中产生不同的发展过程；至少一图有两种有效繁荣方案。
- 实际 Unity Play 检查人物、碰撞、桥、Tab、悬停、对象升降级、恢复与通关，并记录 Profiler 性能；不能只以纯逻辑测试宣称可玩。

## 19. 最终主题判断

规则结构与“涌现”贴合，最有辨识度的是“金富集改变土地状态”和“村庄利用环境又反过来改变环境”，水土变化提供空间上的反馈。

主题是否在成品中成立，取决于反馈链是否真的由统一规则运行、是否能被看懂、是否允许不同干预得到不同结果。预制体是这些结果的视觉表达；不断增加规则数量不会自动提高涌现感。

优先实现并展示小而完整的因果链，比把所有系统做成互不相干的数值条更能体现本次主题。
