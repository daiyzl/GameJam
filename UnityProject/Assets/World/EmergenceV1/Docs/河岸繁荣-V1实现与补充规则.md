# 河岸繁荣 V1：实现与补充规则

日期：2026-10-10。配合《河岸繁荣-五行涌现-完整设计稿-v1.0.md》使用；以下时间与树木规则覆盖旧稿对应描述。

## 本次明确的规则

1. 新树建立前，检查以目标格为中心的 3×3 范围，包括目标格，共 9 格。已有树苗、树、树林的格子数量必须 **小于 4**。一格树林仍算一个有树格；草地不计入。
2. 密度检查约束新树建立，不会为了密度上限删除已存在的树。同一模拟子步内按固定顺序预留萌发位置，后面的种子能看到前面的新树，避免同时萌发绕过限制。被阻止的种子留在格内，条件改善后再尝试。
3. 木工具只投放种子。无种子的水土地只能长草。萌发还要求地块安全、非矿点、金低于死地下限、足够水土、没有火。萌发后木量持续积累，每增加 1 木消耗 1 土、2 水；不足时停止。每时段内部以 0.5 秒子步结算，因此也可利用本时段流入的水。
4. 树木形态由本格木量决定：`0 < 木 < 3` 树苗，`3 ≤ 木 < 8` 单树，`木 ≥ 8` 树林。遭受采伐、金压制或火灾后也可能降级或死亡。阈值集中在 `V1Settings`，不由 Prefab 决定。
5. 一天分为早晨、中午、傍晚。只有点击 **渡过时段** 才结算：早晨→中午→傍晚→次日早晨。人物移动、打开页面、等待、切换工具均不推进环境；投放先改变存量，反应在下次结算执行。
6. 一次点击暂代表 10 秒模拟时间，拆成 20 个子步。它是调参用的模拟长度，不要求玩家等待 10 秒。雨粒子、人物行走和动物向新位置的视觉过渡使用现实时间，不额外产生资源或推进逻辑。

## V1关卡

40×28 地图，Tilemap 起点为 (-4,-2)。初始人物在 (9.5,4.5)，村庄中心 (9,8)，人口 8，位于西岸。木桥连接南侧小径，石桥连接北侧河段。初始状态包含有限矿点、树林、草料、养殖群、野生动物、含金高地／低盆地、污染水和泥沙。

教学标记 (7,6) 用于播种；东岸 (23,8) 的 3×3 范围已有四个树格，可对照观察种子被密度限制。西北 (3…7,14…18) 是金富集区域，最低处 (5,16)。上游 (13,20) 附近有污染水，(12,16) 附近有初始泥沙淤积。

教学只检查结果：渡过时段→玩家播种成功→玩家树成熟→真实采矿采木→野生迁移与养殖繁殖→繁荣至少65且保持5个时段。达到持续繁荣后完成这些教学结果才显示“教学通关”。教学不会直接修改人口、生成必胜矿点或指定洪水结局。

玩家可以继续沙盒建设。恶化导致减员、资源断供、迁移或搬离，不锁死关卡。重开恢复原始地图、人物、居民、动物和数据。

## 首版实现口径

| 系统 | V1行为 |
| --- | --- |
| 地块数据 | 集中数组，以 Tilemap 单元坐标读取；不在每个地块添加脚本 |
| 金 | 金>木压制木；a=8、b=20；死地要求木=0；未成矿金在5×5可达范围寻找低处，沿路径搬运；矿点锁定到归零 |
| 矿物来源 | 初始有限存量、含矿土体侵蚀释放、玩家无限投放；没有自动凭空生金 |
| 水土 | 四邻格按高度+水量水头流动；源头补水、出口排水；搬运污染、泥沙与已有矿物；侵蚀降低土体，沉积抬高河床 |
| 污染与火 | 生产、开采、死地、燃烧产生污染；水搬运、扩散、植物和炉具处理污染；弱火烧植物，火>金才损金；村庄火灾消耗木材、损住房，受灾期间不扩建 |
| 村庄 | 每村36格；范围可重叠，双方中心排除；从真实树和矿采木金；库存用于工具、住房和炉具；人口／承载／安全决定发展与衰退 |
| 村庄外观 | 小、中、大三个不同Prefab，人口18与28切换，扩建先检查占地；不是放大同一张村庄图片 |
| 动物 | 鹿、兔、牛、鸡支持野生／养殖状态；首村先配置牛鸡种畜，野外包含四种动物；真实草料、健康、配偶、周期和容量约束繁殖 |
| 工具页 | Tab 独立页面，五行无限投放；木始终一粒种子；另有垫高、挖低、安排局部降雨 |
| 时段画面 | 早中晚背景图展示在时间面板，地面和水体切换色调；没有用整张背景图覆盖可玩地图 |

草是独立生物量，不能当木材采伐。首版每增加1草消耗0.4土、0.8水；成熟树可向相邻格传播种子。土的养分与地形高度分开，土工具补养分，地形工具每次改变高度0.2。

默认采矿上限0.14金／模拟秒、采木0.15木／模拟秒，按工具与安全条件缩放；保留树木至少1.5木。连续4个恶化时段尝试迁移。繁荣权重沿用旧稿方向：健康人口40、生活20、生态20、野生10、养殖10。
